# Student Performance Analysis

## Project Overview
This project analyzes student study hours, attendance, and marks.
It uses data visualization and machine learning to estimate student marks.

## Objectives
- Inspect and clean student data
- Analyze student performance
- Visualize marks, study hours, and attendance
- Predict marks using Linear Regression
- Display results through a Streamlit application

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Streamlit

## Dataset
The sample dataset contains:
- Student
- Study_Hours
- Attendance
- Marks

## Machine Learning
A Linear Regression model uses study hours and attendance
to estimate student marks.

## How to Run
1. Install the required libraries.
2. Keep app.py and cleaned_students.csv in the same folder.
3. Run: streamlit run app.py

## Limitations
The sample dataset contains only six student records.
Predictions are for demonstration and are not reliable
enough for real academic decisions.
